# 소프트웨어 요구사항 명세서(SRS) v0.1

## 1. 문서 목적과 범위

이 문서는 「고객 요구사항 — 교내 분실물 관리 서비스」를 바탕으로, 이번 개발 범위에 포함된 요구사항을 기능 요구사항, 비기능 요구사항, 정책으로 정리한다. 실제 개인정보와 학교 인증 연동은 이번 범위에서 다루지 않는다.

## 2. 기능 요구사항

| ID | 기능 요구사항 | 근거 | 검증 기준 |
|---|---|---|---|
| FR_01 | 사용자는 분실물의 보관 여부를 조회할 수 있어야 한다. | NEEDS_1, SC1 | 등록된 물품을 조회했을 때 보관 여부가 표시된다. |
| FR_02 | 사용자는 보관 중인 분실물의 보관 위치를 조회할 수 있어야 한다. | NEEDS_1, SC1 | 보관 중인 물품을 조회했을 때 등록된 보관 위치가 표시된다. |
| FR_03 | 습득 학생은 습득한 물품을 앱으로 바로 등록할 수 있어야 한다. | NEEDS_2, SC2 | 습득 학생이 앱에서 물품 정보를 입력하여 새 분실물 기록을 저장할 수 있다. |
| FR_04 | 행정 담당자는 분실물 센터로 접수된 습득 물품을 등록할 수 있어야 한다. | NEEDS_2, SC2 | 담당자가 센터 접수 물품 정보를 입력하여 새 분실물 기록을 저장할 수 있다. |
| FR_05 | 행정 담당자는 등록된 분실물의 상태를 보관 중 또는 인도 완료로 기록하고 변경할 수 있어야 한다. | NEEDS_3, SC3 | 물품 상태를 변경한 뒤 조회 화면에서 변경된 상태가 구분되어 표시된다. |
| FR_06 | 사용자는 보관 담당 부서와 문의 방법을 확인할 수 있어야 한다. | NEEDS_4, SC6 | 조회 화면 또는 안내 화면에서 담당 부서와 문의 방법이 표시된다. |

## 3. 비기능 요구사항(품질 요구사항)

| ID | 품질 속성 | 비기능 요구사항 | 근거 | 검증 기준 |
|---|---|---|---|---|
| NFR_01 | 사용성 | 학생은 행정실 방문 전에 보관 여부, 보관 위치, 문의 방법을 확인하고, 습득 학생은 앱에서 물품 정보를 등록할 수 있도록 화면을 이해하기 쉬운 형태로 제공해야 한다. | NEEDS_1, NEEDS_2, NEEDS_4 | 대표 사용자 10명 중 9명 이상이 도움 없이 조회·문의·습득물 등록의 각 대표 과업을 완료한다. 이 수치는 일반 제안 목표이다. |
| NFR_02 | 효율성 | 행정 담당자의 등록 업무 부담을 줄일 수 있도록 물품 등록에 필요한 입력 절차를 단순하게 구성해야 한다. | NEEDS_7 | 일반 제안 목표: 대표 물품 정보 1건을 3분 이내에 등록한다. 측정 환경과 기준 시점은 고객과 확정한다. |
| NFR_03 | 개인정보 보호 | 조회 화면에는 개인 휴대전화 번호를 공개하지 않아야 한다. | NEEDS_6, SC8 | 조회 화면과 안내 화면에 개인 휴대전화 번호가 표시되지 않는다. |
| NFR_04 | 데이터 안전성 | 실제 개인정보를 저장하거나 학교 인증 시스템과 연동하지 않아야 하며, 가상 데이터만 사용해야 한다. | C_1 | 등록·조회 데이터와 연동 기능을 점검하여 실제 개인정보 및 학교 인증 연동이 없음을 확인한다. |

## 4. 정책

| ID | 정책 | 근거 | 적용 방법 |
|---|---|---|---|
| Pol_01 | 분실물 조회 시 개인 휴대전화 번호를 공개하지 않는다. | NEEDS_6, SC8 | 문의가 필요하면 개인 번호 대신 담당 부서와 문의 방법을 안내한다. |
| Pol_02 | 서비스는 가상 데이터만 사용하며 실제 개인정보를 취급하지 않는다. | C_1 | 화면, 저장 데이터, 예시 데이터에 실제 개인정보를 사용하지 않는다. |
| Pol_03 | 학교 인증 시스템과의 연동은 이번 개발 범위에서 제외한다. | C_1 | 로그인·학교 계정 인증 연동 기능을 구현하지 않는다. |
| Pol_04 | 사진 등록·비교를 통한 유사 분실물 조회는 이번 개발 범위에서 제외한다. | SC5 | 사진 업로드 및 자동 매칭 기능을 제공하지 않는다. |
| Pol_05 | 사진 매칭 결과의 자동 알림 기능은 이번 개발 범위에서 제외한다. | SC7 | 수신 정보 등록 및 자동 발송 기능을 제공하지 않는다. |
| Pol_06 | 분실물 상태는 보관 중과 인도 완료로 구분하여 관리한다. | NEEDS_3, SC3 | 등록 및 조회 화면에서 두 상태를 별도로 표시한다. |
| Pol_07 | 습득물 등록은 등록 경로와 역할에 따라 구분한다. 습득 학생은 앱으로 직접 등록하고, 행정 담당자는 분실물 센터로 접수된 습득 물품을 등록한다. | NEEDS_2, SC2 | 학생 앱 등록과 센터 접수 등록을 각각 제공하고, 각 기록의 등록 경로를 구분한다. |
