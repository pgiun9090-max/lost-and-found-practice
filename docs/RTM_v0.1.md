# 요구사항 추적표(RTM) v0.1

## 1. 목적

이 표는 고객 요구사항 문서의 요구가 SRS v0.1의 기능 요구사항, 비기능 요구사항, 정책에 반영되었는지 추적한다. 수치 기준은 고객 요구사항에 아직 정해져 있지 않아, 검증을 위한 일반적인 제안 목표로 표시한다.

## 2. 요구사항 추적표

| ID | 고객 요구사항 ID·내용 | 출처·범위 | SRS 추적 ID | 반영 상태 | 검증 기준 또는 제안 목표 |
|---|---|---|---|---|---|
| 01 | NEEDS_1 — 분실 학생은 방문 전에 물품의 보관 여부와 위치를 확인할 수 있어야 한다. | S1, SC1 | FR_01, FR_02, NFR_01 | 반영 | 등록된 물품의 보관 여부와 위치가 조회 결과에 표시된다. 사용성 검증 시 대표 사용자 10명 중 9명 이상이 도움 없이 해당 정보를 찾는다. |
| 02 | NEEDS_2 — 습득 학생은 습득한 물품을 앱으로 바로 등록하고, 행정 담당자는 분실물 센터 접수 습득 물품을 등록할 수 있어야 한다. | 확정 사항, SC2 | FR_03, FR_04, NFR_01, Pol_07 | 반영 | 습득 학생은 앱에서, 행정 담당자는 센터 접수 등록 화면에서 새 물품 기록을 저장할 수 있다. 대표 사용자 10명 중 9명 이상이 도움 없이 등록 과업을 완료하는 것을 일반 제안 목표로 한다. |
| 03 | NEEDS_3 — 행정 담당자는 보관 중인 물품과 인도 완료 물품의 상태를 기록하고 구분할 수 있어야 한다. | S2, SC3 | FR_05, Pol_06 | 반영 | 상태를 변경한 뒤 조회 결과에서 보관 중과 인도 완료가 구분되어 표시된다. 상태 변경 권한과 정정 방법은 추후 확정한다. |
| 04 | NEEDS_4 — 분실 학생은 보관 담당 부서와 문의 방법을 확인할 수 있어야 한다. | S5, SC6 | FR_06, NFR_01 | 반영 | 조회 또는 안내 화면에 담당 부서와 문의 방법이 표시된다. |
| 05 | NEEDS_5 — 습득 학생은 물건을 맡길 장소를 알고 싶다. | S3, SC4 | 해당 없음 | 미정 | 프로그램 기능 포함 여부와 기존 안내 수단을 먼저 결정한다. |
| 06 | NEEDS_6 — 조회에 필요한 공개 정보 범위를 정하고, 개인 휴대전화 번호는 공개하지 않는다. | S4, SC8, C_1 | NFR_03, Pol_01 | 반영 | 조회·안내 화면에서 개인 휴대전화 번호가 0건 표시된다. 다른 공개 항목은 추후 확정한다. |
| 07 | NEEDS_7 — 행정 담당자의 물품 등록 부담을 줄여야 한다. | S2, SC2 | NFR_02 | 반영 | 일반 제안 목표: 담당자가 대표 물품 정보 1건을 3분 이내에 등록한다. 측정 환경과 기준 시점은 고객 확인이 필요하다. |
| 08 | 공통 제약 C_1 — 가상 데이터를 사용하고, 실제 개인정보와 학교 인증 연동은 제외한다. | C_1 | NFR_04, Pol_02, Pol_03 | 반영 | 실제 개인정보 저장 및 학교 인증 연동이 각각 0건인지 점검한다. |
| 09 | 제외 범위 — 사진을 올려 비슷한 분실물을 조회한다. | S5, SC5 | Pol_04 | 제외 반영 | 사진 업로드 및 자동 매칭 기능을 제공하지 않는다. 후속 개선 후보로 관리한다. |
| 10 | 제외 범위 — 사진 매칭 결과를 분실 학생에게 자동 알린다. | S5, SC7 | Pol_05 | 제외 반영 | 수신 정보 등록 및 자동 알림 발송 기능을 제공하지 않는다. |

## 3. 비기능 요구사항 적용 원칙

| ID | 내용 |
|---|---|
| 01 | 고객 요구사항 또는 공통 제약에서 직접 근거를 찾을 수 있는 비기능 요구사항만 추적표에 포함했다. |
| 02 | 일반적인 품질 속성만을 선언한 항목은 별도 비기능 요구사항으로 추가하지 않았다. 상태 구분은 품질 속성이 아닌 기능 요구사항 FR_05와 정책 Pol_06으로 추적한다. |
| 03 | 성능, 가용성 등은 고객 요구사항에 목표나 필요성이 제시되지 않아 임의로 추가하지 않았다. 정량 측정이 필요한 등록 업무 부담에는 일반적인 제안 목표를 07번 행에 제시했다. |
